Как обновить сайт на GitHub Pages:
1. Открой свой репозиторий ORNIVAISE.
2. Нажми Add file → Upload files.
3. Загрузи СОДЕРЖИМОЕ этой папки, а не zip-файл.
4. Подтверди Commit changes.
5. Подожди 1–3 минуты.
6. Открой сайт и нажми Ctrl + F5.

Эта версия сделана специально ближе к утверждённому макету v5.
